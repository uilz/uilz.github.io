# 伴记 · 设计系统法典（DESIGN.md）

> V2-Iter3 立典。一切页面/组件的视觉决定以本文为准；代码的真相在 `src/ui/styles/base.css`（令牌）与
> `src/ui/styles/paper.css`（纸方言），本文是它们的账本。**新页面必须 obey；改令牌先改账。**

## 2. 排印尺度

- 字族：`--bj-display`（Georgia/宋体系衬线，题字/按钮/耳语）· `--bj-body`（system/PingFang，正文）· 等宽 `ui-monospace…`（代码纸 R9）。
- 尺度：17/19 题与 h3 · 15.5–16 正文（卡内 15.5、编辑 16=iOS 缩放线）· 13 小注/题签/格式 chip · 11.5–12 纵深耳语 · 10 角标。**新字阶先入账再加数。**
- 排印语气：display 字带 `letter-spacing .1–.3em`（衬线题字呼吸），负 margin 收尾（`margin-right:-Xem`）。

## 3. 间距与圆角

- 8px 栅格为主律：画布 margin 16/24 · 卡衬距 12/14（令牌 `--bj-pad-t/x/b`，材质可覆写）· 热区手机 44px 死线（桌面视觉不动）。
- 圆角只三档：`2px`（画布/chip）· `3px`（卡/菜单项）· `999px`（胶囊按钮）；`4px` 留抽屉按钮。

## 4. 阴影（只有四枚，禁第五）

| 令牌 | 语义 |
|---|---|
| `--bj-shadow` | 纸搁桌上（基线、**选中态**） |
| `--bj-shadow-lift` | 浮起件（菜单/抽屉/浮钮/Toast） |
| `--bj-lift` | **拖拽在途专用**（0 2px 6px 12% + 0 6px 18px 20%，暖棕两层） |
| `inset 0 0 40px` | 画布纸心微暗（构图，不算 shadow 令牌） |

## 5. 动效

- `--bj-move:160ms` 基线；`120ms ease-out` 落点/抬升入；`180ms` 落桌/纸落定（`bj-settle`）；`200ms` 脉冲；`≤1.4s` 耳语全灭（钤印）。
- **只动 transform/opacity/filter**；`prefers-reduced-motion` 全局归零既有。动效即语义：无信息的装饰动效不许存在。

## 6. 纸的方言 · 材质图（`data-paper="<kind>"` → paper.css 一选择器）

| 型 | 纸 | 表面（面，非框） |
|---|---|---|
| text/手记 | 宣纸 | 基线 `--bj-card`，零附加——素净即签名 |
| markdown | 宣纸+朱丝 | 版心左沿 2px `--bj-zhu` 色带 |
| image / video | 照片纸 | `--bj-paper-photo` 更白、衬距 8px、题签落宽下摆（宝丽来血脉） |
| audio | 录音纸条 | 基线 + 28px 横线 `--bj-rule`（约 5% 墨，克制到近耳语） |
| file / pdf | 资料纸 | `--bj-paper-doc` 略灰 + 右上 10px 发丝狗耳（折背=纸翻非描边） |
| code | 代码格 | 基线 + 16px 方格 `--bj-grid` |
| link | 题签 | 基线、上下衬收 8px、URL 发丝线（无盒） |
| container | 垫纸 | `--bj-mat` 半透深一档 + 虚线发丝 + 不投影 |
| 未知型 | 宣纸 | 无选择器命中即基线（兜底不撒谎） |

**折角判例（对账 V2-Iter2）**：日历折角=「那天贴过照片」（6px 墨痕、长在格子上）；卡片狗耳=「这一张是资料」（10px 纸翻、长在纸上）。两物两层、语义互斥，且画布上图纸永不挂折角——裁决不碰撞，狗耳留右上（纸的自然角）。
**新增一型纸 = paper.css 加一个选择器 +（如需）一枚令牌**；渲染器永不碰材质。

## 7. 组件变体与法

1. **夜读法**：可读信息（题签、尺寸、角标、状态）夜低下限 `--bj-ink-soft`，禁 `--bj-ink-faint`；白班耳语才许 faint。材质两班必须各配夜值（缺夜档=非法令牌）。
2. **pill（胶囊）**：`999px`+发丝边+surface 底——只配动作（夹带/存一份/翻开/撕线签）。
3. **quiet-btn**：44px 圆热区、wash 底按态、无永久边框。
4. **seg-underline（V2-Iter3·#15）**：段开关=题字旁低语——整段无框，亮者 `--bj-ink`+2px 朱丝下划，暗者 faint，禁垫色禁边框。
5. **fmt-quiet（#16）**：格式切换 ≤13px 小注——无饼边，亮者自墨+下划，手机热区仍 44px。
6. **receipt（便签/Toast）**：唯一回执通道，发丝边温赭警，叠放席位 ≤3。
7. **stamp（钤印）**：竖排两字、无边框、只动 opacity/transform、≤1.4s 自灭、永不过缝（ephemera-never-stored：瞬态永不进存储/契约）。
8. **选中法（D2）**：边沉至 `--bj-ink-soft` + 基线影——选中不是抬起；`--bj-lift`+`scale(1.012)` 是拖拽在途的独占语言（D3）。
9. **接缝法（D4）**：画布 `flex:1 0 auto` 长到滚动窗底缘；底栏浮纸上，只许光晕（radial wash）不许色带。
10. **图 chip 法（D5）**：`chipMaterial(kind)` 纯映射 → `data-material` 材质色 + 12px 角印；宣纸不佩印；缩微材质可收纹理节奏（声纹 8px），血统不变。
11. **纸语 copy voice**：文案是人话不是系统日志（「这台机器展不开这张纸」式）；装饰不配文字，标签不配 emoji（图标=手绘发丝 SVG）。

## 8. 红线

零依赖 · 零绝对 URL · 材质是面不是戏服（各型不加边框/影子） · 暖家族唯一 · 一眼知型 without labels ·
transform/opacity ≤200ms · 瞬态不进库 · 令牌先入账后使用（守门测在 `test/paper-dialect.test.ts`）。
