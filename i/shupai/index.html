从上到下、列从右往左；拖哪个滑块哪个就是精确值，另一个自动从内容反算跟随，永不吃字。

列数是宽度硬约束；字数吃不满时实际列数可能更少（是上限不是配额，永不留空列）；为塞下内容，行数可自动升高。

拖动即以「行数」为准；拖动「列数」后自动转为跟随。

相邻文字列之间的全角空格数；0 = 紧排无间隔，3 ≈ 空一列。

滑块量程会随内容与手写数字自动伸展，不限你定的宽/高；松手空闲后自动缩回。

使用说明

  1. 拖哪个滑块，哪个就是精确值——数字也可以直接写，写哪个哪个为准，另一个从内容反算跟随（列数是上限，装不满则更少列）。
  2. 换行 = 另起一列：新列紧贴上一段最后一列的左侧。
  3. 永不吃字：排不下只会自动加高或超宽提示，绝不丢内容。
  4. 拖格间距调整列距：相邻文字列间的空格数，0 = 紧排无间隔，3 ≈ 空一列。
  5. 点复制，直接粘贴到聊天软件的纯文本输入框即可。

竖排规则：字从上到下排、列从右往左排，格间以全角空格 U+3000 补齐，任何等宽 / CJK 环境下都能对齐。
